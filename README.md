# LAST REP

Ropa de gym original, comprada en Madrid y enviada a México y Ecuador.

**Tienda:** https://mateomolina1.github.io/LAST-REP/

## Cómo actualizar el catálogo

1. Abre `editor-catalogo.html` en tu ordenador, añade o edita productos y pulsa "Descargar catalogo.json".
2. Aquí en GitHub: **Add file → Upload files**, arrastra el `catalogo.json` y pulsa **Commit changes**.
3. En uno o dos minutos la tienda muestra el catálogo nuevo.
